Internal retrieval (trx900)

Use this window to register the internal retrieval of items from inventory. You cannot change a retrieval after you save it. When you save, the system allocates a retrieval number to the entry. You can use this number as a template for future retrievals. The window displays the same item lines as the original entry, and you can enter the number of units to retrieve manually. When you save the transaction, the system assigns a new request number to it.

The inventory level is updated automatically when you save the retrieval. The basis for updating the financial ledger is saved in a specific register, and it is posted after the stockFlow processor has processed the transactions. Enter the ledger analysis of the financial ledger transactions in the Ledger analysis section or in the Preset reference field. The default accounts are retrieved from the item category.

Prerequisites
  • Define storage zones and locations in the Storage configuration window.
  • Enter retrievable items in the Item catalogue window.
  • Make sure the items to retrieve are in inventory.
  • Set up one or more code types with the treatment code 91 (internal retrieval) in the Code types window. Link code types to valid code cycles, which you define in the Sequence manager window.
  • Set up the persons who are authorised to carry out inventory retrievals in the Access roles window under the Shared settings module.
Procedures

Register an internal inventory retrieval

  1. If two or more code cycles are defined for code types with the treatment code 91, select a code cycle in the Cycle selector window, which opens as a pop-up window before you save the entry. If only one code cycle has the status Active, the system selects it automatically.
  2. Enter a description and the user who has authorisation responsibility. Optionally, attach a reference.
  3. Enter the transaction date.
  4. In the Item code field, enter the code of the items to retrieve from inventory.
  5. To use a previously registered retrieval as a template, click Open to open the existing request. The registered items are displayed in the table.
  6. When you register the first line, enter the ledger analysis to state how to post the line. If a template is defined, you do not need to set up a ledger analysis for the remaining lines.
  7. The combination of storage zone and location registered in the item window is the default. To retrieve from another zone and location, override the default.
  8. If the item is split into batches or serial numbers, enter the batch or serial number of the items to retrieve.
    Note: When you stock an item that has the Batch and Date limit options selected in the Item catalogue window, and you give the item a new batch that does not exist in inventory, the Batch details pop-up window opens. In this window, you can complete the Date from and Date to fields. The pop-up window opens only for newly created batches. For an existing batch, click Batch details to view its details.
  9. Enter the number of units to retrieve. If the item has serial numbers, the number must be 1.
  10. Click Confirm.
  11. Click Save. In the Cycle selector pop-up window, select the code cycle to complete the registration.
Tip: If you select a code series with automatic number allocation, the system allocates the inventory transaction number automatically. With manual assignment, you must allocate a transaction number to the inventory retrieval.

Delete rows during registration

  1. Select the check box on the left of each row to delete. You can delete one or more items from the request details.
  2. Click Remove in the menu.
    Warning: You cannot delete a row that has been saved.
  3. In the Data menu, click Confirm.
Fields and options

Request information section

  • Status: Pending means the retrieval has not been posted.
  • Status: Finalised means the retrieval is posted. You cannot change this status. On registration, the status is Pending. The stockFlow processor changes it to Finalised.
  • Description: Optional text that is posted in the financial ledger when the stockFlow processor runs.
  • Responsible: The user who is responsible for this transaction. The user must belong to a role that is defined in the Access roles window with responsibility type General for the inventory control module.
  • Cycle: The accounting cycle in which the item was registered. The cycle must be valid and defined in the Cycle maintenance window. The default is the current cycle.
  • Date: The retrieval date. The default is the current date.

Request details section

  • Item code: The identifier of the item. You can use only listed inventory items.
  • Description: The description of the item.
  • Preset reference: Retrieves a previously saved ledger analysis.
  • Storage zone: The zone from which the item is retrieved. The zone must be valid and defined in the Storage configuration window.
  • Location: The specific location in the zone. This field can be mandatory or optional.
  • Batch ID: The identifier of a batch-tracked item. Mandatory if the item is tracked by batch.
  • Serial ID: The identifier of a serial-tracked item. Mandatory if the item is tracked by serial number.
  • Unit type: The unit of measure for the item. The default is the base unit, which you can override. If you enter a different unit, the system applies a conversion factor.
  • Unit value: The average inventory value of the item.
    Note: This value is indicative. If you use rolling average or FIFO, the field shows the average value. If you use fixed cost, it shows the standard cost. The valuation method determines the actual value, which the stockFlow processor sets.
  • Quantity: The number of units to retrieve. Must be 1 for serial-tracked items and cannot exceed the available inventory.
  • Total value: Calculated as unit value multiplied by quantity.

Ledger analysis section

Use this command to set up the ledger analysis for a line in the table. It requires the same input as the Preset reference field but behaves differently in the following ways:

  • It applies only to the selected line.
  • It uses the default attribute from the authorisation register, for example cost centre 230.
  • You can retrieve a preset and use it as the basis for line-level mapping. If a preset is defined, it is reflected in the transaction line.

Note: If you modify the line, clear the Preset reference field before you save. This overrides any existing preset mapping for the line.

Buttons in this window
  • Confirm: Saves your changes.
  • Reset: Clears all unsaved fields.
  • Retrieve: Searches for and opens an entry in the lookup pop-up window.
  • Duplicate: Copies the current entry.
  • Inventory check: Shows the inventory levels for the selected item.
  • Retrieval printout: Prints the internal retrieval summary in the Retrieval printout window.
  • Batch details: Shows the batch information and dates for the selected batch.
